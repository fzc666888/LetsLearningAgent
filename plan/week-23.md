# 第 23 周 · 工具失败与允许列表

- **日期**：2027-04-05～2027-04-11
- **阶段**：2 · Agent 与多 Agent
- **知识层级**：L3
- **投入**：约 15 小时（Agent 约 12 小时，评测与观测约 3 小时）

## 本周目标

非法参数、超时、工具异常和未知工具都变成观察结果，循环还能结束。

## 完成标准

- 允许列表之外的工具不会执行。
- 工具异常被捕获，观察文本包含错误类型，不包含环境变量的值。
- 超时有上限，测试使用会阻塞的假工具并断言被取消或超时返回。
- 用户可见的最终消息不打印栈跟踪。

## 任务拆分（约 15 小时）

| 时段 | 时长 | 任务 |
|------|------|------|
| 周一 | 2.5h | 【Agent】执行器只接受注册表里的名字。测试未知名字和大小写不一致的名字。 |
| 周二 | 2.5h | 【Agent】参数校验失败时，把字段错误写进观察，让循环有机会修正。测试假模型第二步不再调用工具。 |
| 周三 | 2.5h | 【Agent】为每个工具设置超时。用一个睡眠很久的假工具测试超时观察。 |
| 周四 | 2.5h | 【Agent】捕获工具内部异常。日志可以有栈，返回给模型和用户的文本只保留短错误。加一条断言，确保响应里没有 `OPENAI_API_KEY` 这个值。 |
| 周五 | 2h | 【Agent】把四类失败各做一条命令行演示，记在笔记里：未知工具、坏参数、超时、工具抛错。 |
| 周末 | 3h | 【评测】给失败路径写 8 条轨迹检查：期望的最后状态是停止，且失败工具的执行次数符合预期。跑一遍并记录通过数。 |

## Checklist

- [ ] 允许列表生效
- [ ] 坏参数可被观察
- [ ] 超时有测试
- [ ] 用户响应无栈跟踪
- [ ] 八条失败检查有结果
