# 第 46 周 · 四道系统设计提纲

- **日期**：2027-09-13～2027-09-19
- **阶段**：3 · 生产化与求职
- **知识层级**：L5
- **投入**：约 15 小时（作品约 9 小时，求职约 6 小时）

## 本周目标

每道题都有目标、组件、数据流、失败方式和你作品里的对应实现。

## 完成标准

- 四份提纲各不超过两页。
- 每份都指向仓库里的真实模块或笔记，而不是空泛名词。
- 你能不看稿讲出其中两道的前两分钟。
- 系统基础阅读笔记至少摘了三条可迁移的权衡。

## 任务拆分（约 15 小时）

| 时段 | 时长 | 任务 |
|------|------|------|
| 周一 | 2.5h | 【作品】写 RAG 提纲：切块、索引、检索、生成、引用。标上你的默认 k 和 recall 笔记位置。 |
| 周二 | 2.5h | 【作品】写 Agent 循环提纲：工具允许列表、步数上限、观察、停止原因。 |
| 周三 | 2.5h | 【作品】写评测提纲：题库、recall、轨迹、CI 夹具和真实调用的分界。 |
| 周四 | 2.5h | 【作品 1.5h】写成本提纲：token、缓存、预算停止。【求职 1h】从 System Design Primer 里选一节关于缓存或延迟的内容，摘三条和你作品有关的句子。 |
| 周五 | 2h | 【求职】不看稿讲 RAG 和 Agent 各两分钟，记下卡壳的词，回到提纲里补一句定义。 |
| 周末 | 3h | 【求职】把四道题的开场白写成各四句话，放进 `notes/system-design.md`。 |

## Checklist

- [ ] 四份提纲已写
- [ ] 提纲指向真实笔记
- [ ] 两道题口述过
- [ ] 摘录了三条权衡
- [ ] 开场白已整理
