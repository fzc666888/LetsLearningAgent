# 第 21 周 · 工具模式与单步函数调用

- **日期**：2027-03-22～2027-03-28
- **阶段**：2 · Agent 与多 Agent
- **知识层级**：L3
- **投入**：约 15 小时（Agent 约 12 小时，评测与观测约 3 小时）

## 本周目标

模型选择一个工具后，程序执行它，再把结果送回模型得到最终回答。测试使用假模型。

## 完成标准

- 工具至少三个：安全计算器、当前时间、本地笔记查找。
- 每个工具有名称、说明和参数 schema。
- 假模型指定工具名和参数时，执行器返回观察结果。
- 未知工具名不会被执行，并有测试。

## 任务拆分（约 15 小时）

| 时段 | 时长 | 任务 |
|------|------|------|
| 周一 | 2.5h | 【Agent】用 `ast` 实现只含数字和四则运算的计算器，拒绝属性访问和函数调用。单测覆盖合法式和非法式。 |
| 周二 | 2.5h | 【Agent】实现时间工具和笔记查找工具。笔记查找只读你指定目录中的 Markdown，返回片段和路径。 |
| 周三 | 2.5h | 【Agent】为三个工具写 JSON Schema。执行器根据名称分发，参数先用 Pydantic 校验。 |
| 周四 | 2.5h | 【Agent】写单步循环：读取假模型给出的工具调用，执行，再把观察结果交给第二次假响应。测试断言最终文本来自第二步。 |
| 周五 | 2h | 【Agent】若配置了 `OPENAI_API_KEY`，用真实模型走通一次计算器问题。把工具名和参数记入笔记。没有密钥时，把假模型轨迹保存为夹具并在笔记说明。 |
| 周末 | 3h | 【评测】为三个工具各写两道应触发该工具的问题，记录期望工具名。下周的循环测试直接复用这张表。 |

## Checklist

- [ ] 计算器拒绝任意代码
- [ ] 三个工具都有 schema
- [ ] 单步调用有测试
- [ ] 未知工具被拒绝
- [ ] 六题期望工具名已列出
