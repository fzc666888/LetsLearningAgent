# 第 31 周 · 计划、检索、写作三段流水线

- **日期**：2027-05-31～2027-06-06
- **阶段**：2 · Agent 与多 Agent
- **知识层级**：L4
- **投入**：约 15 小时（Agent 约 12 小时，评测与观测约 3 小时）

## 本周目标

三个角色各有输入输出字段；假模型测试能跑完整条流水线。

## 完成标准

- 计划角色只产出子问题列表。
- 检索角色对每个子问题调用现有检索，汇总来源。
- 写作角色只根据来源写答案，不能新增工具。
- 角色之间传递的字段有类型，缺字段时测试失败。

## 任务拆分（约 15 小时）

| 时段 | 时长 | 任务 |
|------|------|------|
| 周一 | 2.5h | 【Agent】定义三个角色的提示和输出模型。计划的输出是字符串列表。 |
| 周二 | 2.5h | 【Agent】用一张图按固定边串起三个节点。先全部使用假函数。 |
| 周三 | 2.5h | 【Agent】检索节点复用 P1 检索。测试注入假检索，断言每个子问题都被查询。 |
| 周四 | 2.5h | 【Agent】写作节点要求答案附来源 id。假写作函数的测试检查它收到的是检索结果而不是原始长文。 |
| 周五 | 2h | 【Agent】对一个需要两个子问题的题目跑通流水线，保存每段输出。 |
| 周末 | 3h | 【评测】给这条流水线定三条成功标准：子问题数量在 1 到 3、来源非空、答案里的 id 都出现在检索结果中。用今天的轨迹打分。 |

## Checklist

- [ ] 三角色输出有类型
- [ ] 顺序固定
- [ ] 假检索测试通过
- [ ] 写作只看到检索结果
- [ ] 三条成功标准已打分
