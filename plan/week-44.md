# 第 44 周 · 五分钟演示与已知局限

- **日期**：2027-08-30～2027-09-05
- **阶段**：3 · 生产化与求职
- **知识层级**：L5
- **投入**：约 15 小时（作品约 9 小时，求职约 6 小时）

## 本周目标

五分钟内讲完一条路径；没有 `OPENAI_API_KEY` 时仍能展示检索夹具。

## 完成标准

- 演示稿含开场、操作、结果、局限和结束，总时长不超过五分钟。
- 夹具模式的命令写在 README。
- 局限至少包括语料规模、没有鉴权、评测不等于线上效果。
- 你自己计时排练过一次，超时的句子已删掉。

## 任务拆分（约 15 小时）

| 时段 | 时长 | 任务 |
|------|------|------|
| 周一 | 2.5h | 【作品】写演示稿第一版，标出每段秒数。操作步骤与 README 使用同一条命令。 |
| 周二 | 2.5h | 【作品】实现或确认夹具模式：不调用外网也能显示检索结果和一条固定回答。 |
| 周三 | 2.5h | 【作品】把局限写成 README 的一节，和演示稿里的局限用同一份事实。 |
| 周四 | 2.5h | 【作品 1.5h】计时排练并删到五分钟以内。【求职 1h】写下演示后最可能被问的三个问题。 |
| 周五 | 2h | 【求职】为这三个问题各写一个不超过 40 秒的回答，证据指向具体笔记或测试。 |
| 周末 | 3h | 【求职】再排练一次完整演示加一个追问。把最终稿存为 `notes/demo-5min.md`。 |

## Checklist

- [ ] 演示稿有时间分配
- [ ] 夹具模式可运行
- [ ] 局限与 README 一致
- [ ] 排练已压进五分钟
- [ ] 三个追问有回答
