# 第 33 周 · 作品 P4：研究与批评

- **日期**：2027-06-14～2027-06-20
- **阶段**：2 · Agent 与多 Agent
- **知识层级**：L4
- **投入**：约 15 小时（Agent 约 12 小时，评测与观测约 3 小时）

## 本周目标

批评者检查答案中的来源 id 是否真的出现在检索结果里；修订最多一次。

## 完成标准

- 批评节点输出通过或不通过，以及缺失的 id。
- 不通过时写作节点只再跑一次。
- 演示脚本能打印研究输出和批评结论。
- 五道题的记录显示批评是否抓到不存在的引用。

## 任务拆分（约 15 小时）

| 时段 | 时长 | 任务 |
|------|------|------|
| 周一 | 2.5h | 【Agent】写批评函数的规则版本：提取答案里的 id，与检索 id 比较。单测覆盖全部存在、部分缺失、没有任何 id。 |
| 周二 | 2.5h | 【Agent】把批评节点接在写作之后。不通过才回到写作，且状态里的修订次数最多为 1。 |
| 周三 | 2.5h | 【Agent】用假写作结果测试两条边：一次通过直接结束，一次不通过后修订再结束。 |
| 周四 | 2.5h | 【Agent】写 `scripts/agent_p4.py` 和 README 的 P4 一节。 |
| 周五 | 2h | 【Agent】准备五道题，其中两道故意让第一稿带上不存在的 id（用假写作或提示约束）。运行并保存批评结论。 |
| 周末 | 3h | 【评测】把五题结果写成 `notes/p4-critic.md`：抓到几次、漏掉几次、修订后 id 是否变干净。标出规则批评还做不到的一种错误。 |

## Checklist

- [ ] 批评规则有单测
- [ ] 修订最多一次
- [ ] 两条边都有测试
- [ ] README 含 P4
- [ ] 五题批评记录已写
