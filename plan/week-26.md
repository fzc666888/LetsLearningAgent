# 第 26 周 · 条件边与工具循环

- **日期**：2027-04-26～2027-05-02
- **阶段**：2 · Agent 与多 Agent
- **知识层级**：L4
- **投入**：约 15 小时（Agent 约 12 小时，评测与观测约 3 小时）

## 本周目标

条件边可测试；循环有最大次数，到达后进入结束。

## 完成标准

- 路由函数在有工具调用时走向工具节点，否则走向结束。
- 工具节点复用第 23 周的允许列表执行器。
- 最大循环次数写成状态字段，测试能触发上限。
- 一条真实或假模型轨迹显示至少一次回到模型节点。

## 任务拆分（约 15 小时）

| 时段 | 时长 | 任务 |
|------|------|------|
| 周一 | 2.5h | 【Agent】写纯函数 `route(state)`。用两种状态做单测，不编译图也能断言下一节点。 |
| 周二 | 2.5h | 【Agent】把路由接成条件边。工具节点调用现有执行器，并把观察写回消息。 |
| 周三 | 2.5h | 【Agent】在状态里记录循环次数。达到上限时路由到结束，并写入停止原因。 |
| 周四 | 2.5h | 【Agent】用假模型测试：第一次返回工具调用，第二次返回最终回答。断言工具节点只运行一次。 |
| 周五 | 2h | 【Agent】跑一道 P2 里的计算题，确认图的轨迹与手写循环的工具名一致。 |
| 周末 | 3h | 【评测】对照快速开始里的计算器 Agent。写一页差异：你的允许列表、步数上限和停止原因分别落在哪个节点。 |

## Checklist

- [ ] 路由函数有单测
- [ ] 条件边已接上
- [ ] 循环上限会停止
- [ ] 两步假模型测试通过
- [ ] 与 P2 轨迹做过对照
