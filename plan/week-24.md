# 第 24 周 · 作品 P2：工具型单 Agent

- **日期**：2027-04-12～2027-04-18
- **阶段**：2 · Agent 与多 Agent
- **知识层级**：L3
- **投入**：约 15 小时（Agent 约 12 小时，评测与观测约 3 小时）

## 本周目标

P2 有运行说明、演示问题和一页任务成绩。

## 完成标准

- 检索或笔记查找、计算器都在允许列表里。
- 命令行演示一道计算题和一道笔记题。
- 8 个任务记录了期望工具和实际工具，以及是否在五步内停止。
- README 有作品 P2 一节。

## 任务拆分（约 15 小时）

| 时段 | 时长 | 任务 |
|------|------|------|
| 周一 | 2.5h | 【Agent】把 P1 的检索包成只读工具 `search_notes`，参数是查询字符串和 k。沿用允许列表。 |
| 周二 | 2.5h | 【Agent】写 `scripts/agent_p2.py`，打印最终答案和轨迹。默认步数上限为 5。 |
| 周三 | 2.5h | 【Agent】准备 8 个任务：4 个应使用检索，2 个应使用计算器，2 个应直接回答。写成 JSONL。 |
| 周四 | 2.5h | 【Agent】跑这 8 个任务。记录实际工具序列和步数。成绩写入 `notes/p2-tasks.md`。 |
| 周五 | 2h | 【Agent】根据失败任务修一处提示或工具说明，再跑一遍失败项。保留修改前后的结果。 |
| 周末 | 3h | 【评测】写 P2 小节到 README：它能做什么、八题成绩、仍会选错工具的例子。给每题标上是否适合放进以后的回归集。 |

## Checklist

- [ ] 检索已成为工具
- [ ] 演示脚本可运行
- [ ] 八个任务有成绩
- [ ] 失败项有一次修订记录
- [ ] README 含 P2
