# 第 19 周 · 领域语料与作品 P1 起步

- **日期**：2027-03-08～2027-03-14
- **阶段**：1 · LLM 与 RAG
- **知识层级**：L2
- **投入**：约 15 小时（应用约 11 小时，阅读约 4 小时）

## 本周目标

P1 有明确领域、可重复的入库命令，以及至少 15 道领域新题。

## 完成标准

- 领域说明写明语料从哪来、一共多少篇、你为什么选它。语料是你自己的笔记或可再分发的短文档。
- 一条命令能重建该领域索引。
- 在原有题库之外新增至少 15 题，并跑出 recall@k。
- README 出现「作品 P1」一节，含目录和运行步骤。

## 任务拆分（约 15 小时）

| 时段 | 时长 | 任务 |
|------|------|------|
| 周一 | 2.5h | 【应用】选定领域，例如你正在学的 Python 专题笔记。写下范围：包含什么、先不包含什么。准备不少于 8 篇短文。 |
| 周二 | 2.5h | 【应用】把语料放进独立目录。入库命令只扫描该目录。记录篇数和块数。 |
| 周三 | 2.5h | 【应用】为该领域新写至少 15 道题，期望来源指向真实块。并入评测脚本。 |
| 周四 | 2.5h | 【应用】跑 recall@k。把数字和三道错题写进 `notes/p1-baseline.md`。 |
| 周五 | 2h | 【应用 1h】起草 README 的 P1 一节：领域、命令、评测命令。【阅读 1h】列出读者运行 P1 前必须配置的环境变量名。 |
| 周末 | 3h | 【阅读】重读 RAG 论文摘要，并对照你的基线数字。写一页：这个领域里最容易检索失败的问题类型是什么。 |

## Checklist

- [ ] 领域范围已写明
- [ ] 索引可重建
- [ ] 新增至少 15 题
- [ ] 基线召回率已记录
- [ ] README 有 P1 一节
