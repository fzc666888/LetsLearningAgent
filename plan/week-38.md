# 第 38 周 · 数据卷、内容哈希与可重建索引

- **日期**：2027-07-19～2027-07-25
- **阶段**：3 · 生产化与求职
- **知识层级**：L5
- **投入**：约 15 小时（作品约 9 小时，求职约 6 小时）

## 本周目标

删掉容器后数据还在；同一文件再次入库不会制造重复块。

## 完成标准

- SQLite 文件位于命名卷或绑定挂载，路径写在部署笔记里。
- 内容哈希测试仍通过。
- 文档说明如何清空索引并重建。
- 简历草稿里有五条 P1 要点，每条带一个证据。

## 任务拆分（约 15 小时）

| 时段 | 时长 | 任务 |
|------|------|------|
| 周一 | 2.5h | 【作品】为数据库文件配置卷。重启容器后插入的一条记录仍能读到。把步骤记下来。 |
| 周二 | 2.5h | 【作品】核对入库的内容哈希。补一个测试：相同内容第二次调用插入数为 0。 |
| 周三 | 2.5h | 【作品】写重建步骤：停止写入、删除索引文件或表、重新入库、再跑夹具评测。自己执行一次。 |
| 周四 | 2.5h | 【作品 1.5h】把卷和重建命令写进 README 的运行一节。【求职 1h】起草五条作品要点，主语用你做出的行为。 |
| 周五 | 2h | 【求职】改这五条，使每条都含范围、做法和证据（召回率、测试或演示现象）。删掉没有证据的形容词。 |
| 周末 | 3h | 【求职】朗读要点并计时，每条控制在 20 秒内。把最终五条存进 `notes/resume-bullets.md`。 |

## Checklist

- [ ] 重复入库测试通过

- [ ] README 写了卷
