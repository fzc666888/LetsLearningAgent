# 第 45 周 · 作品集说明与简历要点

- **日期**：2027-09-06～2027-09-12
- **阶段**：3 · 生产化与求职
- **知识层级**：L5
- **投入**：约 15 小时（作品约 9 小时，求职约 6 小时）

## 本周目标

每件作品都有问题、做法、证据和取舍；仓库检索不到密钥值。

## 完成标准

- 一份作品集索引链接到 P1–P6 的运行说明。
- 每件作品的证据是数字或可复现现象。
- 用 git 与文件搜索确认跟踪内容里没有密钥值。
- 简历要点更新到六件作品里你最想讲的三件。

## 任务拆分（约 15 小时）

| 时段 | 时长 | 任务 |
|------|------|------|
| 周一 | 2.5h | 【作品】为 P1–P6 各写四行：问题、做法、证据、取舍。集中到 `notes/portfolio.md`。 |
| 周二 | 2.5h | 【作品】在 README 放上索引，检查每条链接的命令现在仍能运行。 |
| 周三 | 2.5h | 【作品】搜索仓库中的密钥形态和 `.env`。确认示例只含 `OPENAI_API_KEY`、`OPENAI_BASE_URL`、`OPENAI_MODEL` 这些名字。 |
| 周四 | 2.5h | 【作品 1.5h】把最能讲的三件作品改成简历子弹。【求职 1h】读 GitHub 关于移除敏感数据的文档，确认你不需要历史清理；若需要，先停下来按该文档处理。 |
| 周五 | 2h | 【求职】朗读三件作品的子弹，每条 20 秒。改掉听不懂的内部文件名。 |
| 周末 | 3h | 【求职】写一段 GitHub 项目简介草稿，不超过 120 字，包含年份、技术栈和一件证据。 |

## Checklist

- [ ] 六件作品都有四行说明
- [ ] README 索引可点
- [ ] 跟踪文件无密钥值
- [ ] 三条简历子弹已朗读
