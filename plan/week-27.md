# 第 27 周 · 检索、判断与生成放进一张图

- **日期**：2027-05-03～2027-05-09
- **阶段**：2 · Agent 与多 Agent
- **知识层级**：L4
- **投入**：约 15 小时（Agent 约 12 小时，评测与观测约 3 小时）

## 本周目标

图包含检索、判断、改写和生成；判断失败时最多改写一次。

## 完成标准

- 检索节点调用已有检索函数，并把块放进状态。
- 判断节点给出相关或不相关。测试里判断函数可替换。
- 不相关时进入改写节点，然后再检索一次；第二次仍不相关则生成「资料不足」。
- 相关时生成答案并保留来源 id。

## 任务拆分（约 15 小时）

| 时段 | 时长 | 任务 |
|------|------|------|
| 周一 | 2.5h | 【Agent】把检索封装成图节点。用假检索返回固定两块，测试状态里的来源 id。 |
| 周二 | 2.5h | 【Agent】写判断节点。先用规则：期望关键词是否出现在块里。规则结果写入状态。 |
| 周三 | 2.5h | 【Agent】添加改写节点和条件边。用测试锁住「只改写一次」：第二次判断失败后不再回到改写。 |
| 周四 | 2.5h | 【Agent】生成节点复用 P1 的问答模板。假生成器测试断言来源被传入。 |
| 周五 | 2h | 【Agent】对自己的语料跑两个问题：一个应判相关，一个应判资料不足。保存两次轨迹。 |
| 周末 | 3h | 【评测】阅读 LangGraph 的 agentic RAG 教程。写一页：教程中的评分、改写和你这张图的对应节点，以及你故意保留的上限。 |

## Checklist

- [ ] 检索节点有测试
- [ ] 判断结果写入状态
- [ ] 改写只发生一次
- [ ] 资料不足路径有断言
- [ ] 教程对照笔记已写
