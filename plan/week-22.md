# 第 22 周 · 有上限的 ReAct 循环

- **日期**：2027-03-29～2027-04-04
- **阶段**：2 · Agent 与多 Agent
- **知识层级**：L3
- **投入**：约 15 小时（Agent 约 12 小时，评测与观测约 3 小时）

## 本周目标

循环在没有新的工具调用或到达五步时停止；两步轨迹有测试。

## 完成标准

- 每一步记录思考摘要、工具名、参数和观察。
- 步数上限为 5，测试能让假模型一直要求工具并断言停止。
- 停止后返回最终回答和完整轨迹。
- 笔记用自己的话复述 ReAct 论文里行动和观察的分工。

## 任务拆分（约 15 小时）

| 时段 | 时长 | 任务 |
|------|------|------|
| 周一 | 2.5h | 【Agent】定义轨迹结构。循环体每次追加一步。没有工具调用时结束。 |
| 周二 | 2.5h | 【Agent】加上最大步数。超过上限时返回已有观察和一句说明，而不是继续请求模型。 |
| 周三 | 2.5h | 【Agent】用假模型编写两步测试：第一步查笔记，第二步给出最终答案。断言工具只执行一次。 |
| 周四 | 2.5h | 【Agent】把第 21 周的三个工具接进循环。命令行打印每步的工具名。 |
| 周五 | 2h | 【Agent】用两道需要两次工具的题手动跑通（真实模型或假模型）。把轨迹贴进笔记。 |
| 周末 | 3h | 【评测】阅读 ReAct 论文摘要和第 2 节。写一页：你的循环与论文中的轨迹有哪些字段对应，五步上限保护的是什么。 |

## Checklist

- [ ] 无工具调用时停止
- [ ] 五步上限有测试
- [ ] 两步轨迹测试通过
- [ ] 命令行能打印轨迹
- [ ] 论文笔记已写
