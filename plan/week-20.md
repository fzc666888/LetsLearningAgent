# 第 20 周 · 作品 P1 收口与阶段复盘

- **日期**：2027-03-15～2027-03-21
- **阶段**：1 · LLM 与 RAG
- **知识层级**：L2
- **投入**：约 15 小时（应用约 11 小时，阅读约 4 小时）

## 本周目标

按 README 能完成一次入库和提问；评测报告与阶段复盘都已写好。

## 完成标准

- 演示步骤不超过 8 步，包含期望看到的来源 id。
- 评测报告含题量、recall@k、两道有依据的回答和两道失败。
- 局限至少三条：语料规模、语言、没有鉴权。
- 阶段复盘对照 L1 与 L2，写出进入 Agent 阶段要复用的模块。

## 任务拆分（约 15 小时）

| 时段 | 时长 | 任务 |
|------|------|------|
| 周一 | 2.5h | 【应用】把演示步骤写进 README，并自己从头走一遍。命令与文档不一致就改文档或改代码。 |
| 周二 | 2.5h | 【应用】整理评测报告到 `notes/p1-report.md`。附上默认检索配置。 |
| 周三 | 2.5h | 【应用】检查仓库：示例配置只有变量名；追踪样例里没有密钥值。 |
| 周四 | 2.5h | 【应用】给 P1 补一个失败路径演示：问一个语料里没有的问题，确认回答会表明缺少依据或来源为空。把表现写进报告。 |
| 周五 | 2h | 【应用 1h】列出 P1 里下一阶段要当成工具调用的函数（检索、入库）。【阅读 1h】重读你的 L1 概念卡，补上结构化输出那条。 |
| 周末 | 3h | 【阅读】写阶段复盘：模板库、解析器、检索、评测、日志各留在哪个文件。标出仍不稳的一个指标。 |
